# pg-prime

A PostgreSQL-only, type-safe TypeScript ORM with first-class migrations and zero runtime dependencies.

> **Status: pre-alpha.** Published on npm — ESM-only, zero dependencies, TypeScript ≥ 5.9, and `pg`
> as an optional peer needed only by the `connection:` form — and the API will change. Entries:
> `pg-prime`, `pg-prime/schema`, `pg-prime/sql`, `pg-prime/codecs`, `pg-prime/driver`.
> Follow progress at <https://github.com/pg-prime/pg-prime>.
