# packages/pg-prime-create/src/index.ts

## Purpose
The library entry of `@pg-prime/create`: the same scaffolder the `create-pg-prime` bin runs, exported so a generator or test can write a project without spawning a process. It re-exports `parseArgs` (`args.ts`), `scaffold` (`scaffold.ts`), the generated `VERSIONS` (`versions.ts`) and the public types (`types.ts`). The bin itself is `src/cli.ts`, which this entry does not export.

## Public API
- `parseArgs(argv): ParseResult` — from `packages/pg-prime-create/src/args.ts:83`; errors are collected, not thrown.
- `scaffold(options: ScaffoldOptions): ScaffoldResult` — from `packages/pg-prime-create/src/scaffold.ts:163`; throws on a non-empty target.
- `VERSIONS: Versions` — the dependency ranges written into a scaffolded `package.json`, from the generated `src/versions.ts`.
- Types `CliOptions`, `PackageManager`, `ParseResult`, `ScaffoldOptions`, `ScaffoldResult`, `Versions` — from `packages/pg-prime-create/src/types.ts`.

## Flow
1. Pure re-exports (`packages/pg-prime-create/src/index.ts:9-19`); importing it reads `../package.json` once (via `packages/pg-prime-create/src/args.ts:16`) and nothing else.
2. `package.json` maps `.` to `dist/index.js` (with a `types@<5.9` stand-in) and `bin.create-pg-prime` to `dist/cli.js`.

## Gotchas
- `src/versions.ts` is generated by `packages/pg-prime-create/scripts/versions.mjs` and git-ignored. A fresh checkout has no such file, so typecheck, build and any import of `index.ts`/`scaffold.ts` fail until it is generated. `build`, `typecheck` and the vitest `globalSetup` (`packages/pg-prime-create/test/globalSetup.ts`) run the script first; `versions.mjs --check` reports a stale file.
- `VERSIONS` pins `pg-prime`, `@pg-prime/kit` and `@pg-prime/testing` as `^<their workspace version>`, and `pg`, `typescript`, `@types/node`, `vitest`, `@electric-sql/pglite` from the kit and root manifests.
- `main`, `resolveOptions`, `templatesDir`, `packageNameFor`, `HELP`, `VERSION` and `detectPackageManager` are exported from their modules but not from this entry.
- `src/unsupported-typescript.d.ts` is the generated TypeScript < 5.9 stand-in for this entry; do not edit it.
- The emitted `.d.ts` must name no module outside the package; `tools/check-dts.mjs:41` asserts `zeroDeps: true`. The public surface is snapshotted in `tools/api-snapshot/pg-prime-create.json`.
- The package has zero runtime dependencies.

## Tests
- No spec targets the entry; see `test/args.test.ts`, `test/scaffold.test.ts`, `test/templates.test.ts` (unit project) and `test/pg/scaffold.e2e.test.ts` (pg project, needs `PG_PRIME_TEST_URL`).
- Run: `pnpm --filter @pg-prime/create exec vitest run --project unit`.
- The installed-tarball shape (bin, export map) is exercised by `tools/create-smoke.mjs`.
