# packages/pg-prime/src/index.ts

## Purpose
The `pg-prime` package root entry (`exports["."]` → `dist/index.js`): a curated, enumerated re-export of the
schema DSL, the `sql` tag, codecs, driver, query builder, session layer, errors, pooler profiles and
observability. Applications import from it; inside the repo `@pg-prime/testing`
(`packages/pg-prime-testing/src/postgres.ts`, `packages/pg-prime-testing/src/mock-pool.ts`) and
`packages/pg-prime-kit/src/schema/types.ts` do too. It defines nothing itself.

## Public API
- Schema DSL from `schema/index.ts` — `pgTable`, column builders (`integer`, `text`, `uuid`, `vector`, …),
  `pgEnum`, `pgView`, `pgMaterializedView`, `defineSchema`, `defineRelations`, extras, and ~100 types.
- Phantom slot symbols — `COLS`, `META`, `OUT`, `REFS`, `SRC`, … (exported only so `.d.ts` emit works).
- From `sql/index.ts` — `sql`, `isFragment`, `toNode`, `asExpr`, identifier helpers, `PgPrimeError`, the
  builder/compiler error classes, and `Fragment`/`TypedFragment`/`SqlTag` types.
- From `codec/index.ts` — every built-in codec, `Registry`, `createRegistry`, `defaultRegistry`,
  `definePgType`, `PgDecodeError`/`PgEncodeError`, and codec types.
- From `driver/index.ts` — `pgDriver`, `PgDriverError`, `normaliseError`, `isServerErrorShape`,
  `toServerErrorData`, and the `Pg*` driver contract types.
- From `query/run.ts` — `pgPrime`, `compileOnly`, `statementStats`, `DbConfig` and related types.
- Session layer — `presets`, `MAX_NOTIFY_PAYLOAD_BYTES`, transaction/listen/copy option types.
- From `errors/index.ts` — every runtime error class (incl. `VersionConflictError`), `ConfigError`, `UsageError`, `SQLSTATE_MAP`,
  `SQLSTATE_CLASS_FALLBACK`, `classForSqlState`, the four `is*Violation` predicates, and error types.
- From `pooler/index.ts` — `POOLER_MODES`, `POOLER_PROFILES`, `profileOf`, and diagnosis types.
- From `observe/index.ts` — `SEMCONV`, `spanAttributes`, `spanName`, hook event and log types.
- Executor — `placeholder`, `clearDescribeCache`, `describeCacheStats`, `CodecMismatchError`, and
  executor/prepared/explain types.
- Operators and helpers — ~80 operators from `query/ops.ts`, `and`/`or`/`not`/`exists`/`asc`/`desc`/`fn`,
  `nest`, `nestNullable`, `omit`, `over`, `SELECT_SOURCE`, and the query/handle types (`Db`, `Tx`, `Query`, …).

## Flow
1. Module evaluation re-exports each block in order: schema, symbols, sql, codecs, driver, query, session,
   errors, pooler, observe, executor, operators (`packages/pg-prime/src/index.ts:32`).
2. The build (`tools/build-package.mjs`) emits `dist/index.js` and `dist/index.d.ts` and copies
   `src/unsupported-typescript.d.ts` into `dist/`.
3. Consumers on TypeScript < 5.9 resolve the `types@<5.9` condition to that stub instead of
   `dist/index.d.ts`.

## Gotchas
- Curated, not `export *`: `OPS`/`CONFIRMABLE` (from `query/types.ts`), `RANGE_ELEMENT_NAMES`, AST
  constructors, planner/emitter and other internals are deliberately omitted (`packages/pg-prime/src/index.ts:4`).
- Adding an export to a module does not make it public; it must be added here and the API golden
  regenerated. `packages/pg-prime/test/query/index.test.ts` lists expected names by hand, not exhaustively.
- `PgPrimeError` is exported in the `sql` block, not the errors block (`packages/pg-prime/src/index.ts:232`).
- Internal helpers stay private: `HookBus`, `mapError`, `resolveErrorOptions`, `captureCallSite`,
  `diagnose`/`diagnosePooler` (reached via `db.*` methods), `alterRoleHint`, `isTransactionPooled`.
- `src/unsupported-typescript.d.ts` is generated by `tools/api-snapshot.mjs` from
  `tools/api-snapshot/pg-prime.json`; never edit it by hand. Every root value and type name maps to an
  `Unsupported` identity alias whose `ERROR` message names the TypeScript 5.9 requirement.
- After changing this file, build and run `pnpm api-snapshot` (rewrites golden and stub); CI runs
  `pnpm api-snapshot:check`, which fails on drift and requires every subpath (`pg-prime/sql`, `/schema`,
  `/codecs`, `/driver`) to export a subset of the root.
- The package is `sideEffects: false`; nothing in this file may have side effects.

## Tests
- `packages/pg-prime/test/query/index.test.ts` (unit): every expected name is present, internal names are
  absent, and a query compiles through the barrel alone.
- Run: `pnpm --filter pg-prime exec vitest run test/query/index.test.ts`.
- Repo tools: `pnpm api-snapshot:check`, `pnpm check:dts`, `pnpm treeshake`, `pnpm pack-smoke` (which
  verifies the stub against TypeScript 5.8.3).
- Uncovered by vitest: type-only exports are checked only by the API snapshot tool.
