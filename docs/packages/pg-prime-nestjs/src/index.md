# packages/pg-prime-nestjs/src/index.ts

## Purpose
The `@pg-prime/nestjs` entry: the module, decorators, tokens and `provideAddOn`, plus a re-export of
`@pg-prime/context`'s host, error and settings types. `./testing` (`src/testing.ts`) is the second
entry.

## Public API
- `PgPrimeModule`, `PgPrimeModuleOptions`, `PgPrimeModuleAsyncOptions` (`src/module.ts`).
- `Transactional` (`src/transactional.ts`); `RequestTransaction`, `RequestOptions`,
  `RequestTxMode` (`src/request.ts`); `InjectDb`, `InjectHost`, `getDbToken`, `getHostToken`
  (`src/tokens.ts`); `provideAddOn` (`src/add-on.ts`).
- Re-exported: `TransactionHost`, `ContextError`, `HostTxOptions`, `Propagation`, `Setting`,
  `Settings`.
- Not exported: `RequestInterceptor`, `register`, `hostOf`, `optionsToken`, `DEFAULT`.

## Flow
1. Importing the entry loads `@nestjs/common`, `@nestjs/core`, `rxjs`, `@pg-prime/context` and
   `pg-prime`; nothing runs until `forRoot` is called.

## Gotchas
- No decorator syntax in `src/`: `Inject`, `SetMetadata` and the method decorator are called as
  functions and providers are `useFactory`, so the build needs no decorator settings
  (`tsconfig.build.json` turns them off; tests turn them on in `tsconfig.json`).
- `src/unsupported-typescript.d.ts` is generated by `tools/api-snapshot.mjs`.

## Tests
- `tools/api-snapshot/pg-prime-nestjs.json` — the export golden (`pnpm api-snapshot:check`).
- `fixtures/treeshake/nestjs-module/` — the module-set and size golden (`pnpm treeshake`).
- `packages/pg-prime-nestjs/test/pack-smoke.ts` — boots `PgPrimeModule` from the tarballs.
