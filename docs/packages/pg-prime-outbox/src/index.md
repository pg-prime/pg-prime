# packages/pg-prime-outbox/src/index.ts

## Purpose
The `@pg-prime/outbox` entry: topic declarations, the public types, the error classes, `pgOutbox`,
`migrationSql` and the two sinks. `define.ts`, `types.ts` and `errors.ts` hold the declarations it
re-exports.

## Public API
- `defineOutbox(topic, opts?)` → frozen `OutboxDef<T>` (`packages/pg-prime-outbox/src/define.ts:49`);
  defaults `partitions` 16, `ordered` true, `keepDeliveredMs` 86 400 000.
- `OutboxDefOptions`, `OutboxDef`, `OutboxCodec`, `PayloadOf`, and `StandardSchemaV1` (a copy of the
  Standard Schema interface, `packages/pg-prime-outbox/src/define.ts:4`).
- Public interfaces in `packages/pg-prime-outbox/src/types.ts`: `WriteOptions`, `WriteResult`,
  `OutboxRecord`, `ParkedRecord`, `DeliveryContext`, `DeliveryResult`, `OutboxSink`, `RetryOptions`,
  `RelayOptions`, `Relay`, `PartitionStats`, `OutboxStats`, `OutboxTopic`, `InternalKind`,
  `OutboxHooks`, `OutboxConfig`, `Outbox`.
- Errors (`packages/pg-prime-outbox/src/errors.ts`): `OutboxLeaseLostError` (`OUTBOX_LEASE_LOST`),
  `NonRetryableSinkError` (`OUTBOX_NON_RETRYABLE`), `SchemaVersionError` (`OUTBOX_SCHEMA_VERSION`),
  `NotStartedError` (a `UsageError`, `OUTBOX_NOT_STARTED`), `PayloadError` (`OUTBOX_PAYLOAD`, with
  `issues`).
- `pgOutbox`, `migrationSql`, `functionSink`, `webhookSink`, `WebhookSinkOptions` — see their module
  docs.

## Flow
1. `defineOutbox` validates the name, `partitions` (integer 1..1024) and `keepDeliveredMs`
   (non-negative safe integer), throwing `UsageError`.
2. `pgOutbox` turns a `define` map into the typed `topics` registry; `PayloadOf` reads each payload
   type off the definition's `schema`/`codec` members.

## Gotchas
- `OutboxDef<T>` carries `T` only through `schema` and `codec`; `PayloadOf` infers it from them, so
  a definition without either still types its payload from the explicit `defineOutbox<T>`.
- `NotStartedError` extends `UsageError`, so pg-prime's transaction retry never re-runs it.
- `src/unsupported-typescript.d.ts` is generated by `tools/api-snapshot.mjs`; never edit it by hand.
