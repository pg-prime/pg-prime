# packages/pg-prime-kit/src/diff/ddl.ts

## Purpose
Turns a `DiffResult` into unordered DDL `Statement`s with dependency ids, lock class and hazard codes, including the lock-safe rewrites. Callers: `generate.ts` (both `generate` and `generateFromDatabases`), `checkpoint/checkpoint.ts`, `prove/prove.ts`, `prove/temp-schema.ts`, `cli/commands/baseline.ts`; output goes to `diff/order.ts`. Uses `sql/ident.ts` for all quoting and constraint naming.

## Public API
- `BuildResult` — `{ statements, diagnostics }`; diagnostics include every `diff.diagnostics` entry plus the builder's own.
- `BuildOptions.volatileDefaults` — encoded `default` ids the catalog found volatile; else harvested from `volatile_default` diagnostics, else the text fallback.
- `BuildOptions.noSafeRewrite` — emit literal DDL instead of the lock-safe forms (`--no-safe-rewrite`).
- `BuildOptions.emptyTables` — encoded table ids proven empty; suppresses MF hazards only, never LK.
- `BuildOptions.multiFile` — the caller can write a `concurrent` companion file; enables the `CONCURRENTLY` and volatile-default split rewrites.
- `BuildOptions.noConcurrentIndexes` — encoded index ids opted out of the `CONCURRENTLY` rewrite (`index().concurrently(false)`).
- `columnClause(colId, payload, defaultExpr?)` — one column definition: type, collation, generated/identity/default, NOT NULL (named only when user-named), `NOT VALID`.
- `mentionsVolatileFunction(expression)` — regex fallback for LK109 over a fixed list of rewriting built-ins.
- `buildStatements(diff, desired, options?): BuildResult` — never throws for unsupported changes (reports `unsupported_alter` / `unsupported_rename`); throws only on malformed ids or a comment target with no `COMMENT ON` syntax.

## Flow
1. Resolve volatility, empty tables, and the created/dropped table, type and column sets from `diff.deltas` (`packages/pg-prime-kit/src/diff/ddl.ts:199-223`).
2. Emit one `RENAME` per `diff.renames` record, all at `PHASE.rename` (`packages/pg-prime-kit/src/diff/ddl.ts:277-415`).
3. `addEnumValue` → `ALTER TYPE … ADD VALUE IF NOT EXISTS … BEFORE|AFTER`, `commitBoundaryAfter` (`packages/pg-prime-kit/src/diff/ddl.ts:419-441`).
4. `create` per kind (`packages/pg-prime-kit/src/diff/ddl.ts:443-756`); `alter` per kind (`packages/pg-prime-kit/src/diff/ddl.ts:758-938`); `drop` per kind (`packages/pg-prime-kit/src/diff/ddl.ts:940-1099`).
5. Drops carry `releases` from `referencesHeldBy` (outgoing `depends`/`evaluates` targets plus the schema) so referencing objects drop before their referents (`packages/pg-prime-kit/src/diff/ddl.ts:263-274`).
6. Return statements in delta order; ordering is `orderStatements`' job (`packages/pg-prime-kit/src/diff/ddl.ts:1106`).

## Gotchas
- **Rewrite gate.** `concurrentOk` needs `multiFile`, no `noSafeRewrite`, and an existing non-partitioned table (`packages/pg-prime-kit/src/diff/ddl.ts:245-250`); `packages/pg-prime-kit/src/generate.ts:276` retries with `multiFile: false` if `splitStages` declines.
- **Volatility.** An empty `volatileDefaults` set is treated as "not supplied" and falls back to the regex (`packages/pg-prime-kit/src/diff/ddl.ts:202-203`). The catalog test is `provolatile <> 'i'` (`packages/pg-prime-kit/src/catalog/extract.ts:412`), which includes STABLE `now()`; the regex fallback deliberately excludes it (`packages/pg-prime-kit/src/diff/ddl.ts:135-142`).
- **Renames.** Table → BC101, column → BC102, constraint/index/type/sequence → BC104, enum label → BC105 with `lockClass: "none"`, schema → BC101; any other kind → `unsupported_rename` error (`packages/pg-prime-kit/src/diff/ddl.ts:280-414`).
- **Schema.** `CREATE SCHEMA IF NOT EXISTS`; drop is `DROP SCHEMA IF EXISTS` with DS101, no `CASCADE` (`packages/pg-prime-kit/src/diff/ddl.ts:446-457`, `packages/pg-prime-kit/src/diff/ddl.ts:1082-1094`).
- **Extension.** `CREATE EXTENSION IF NOT EXISTS … SCHEMA`; only a schema change alters (`SET SCHEMA`); drop is a no-op because `diffIR` never emits one (`packages/pg-prime-kit/src/diff/ddl.ts:586-603`, `packages/pg-prime-kit/src/diff/ddl.ts:825-845`, `packages/pg-prime-kit/src/diff/ddl.ts:1008-1013`).
- **Sequence.** Created without `OWNED BY`, ownership set by a separate `ALTER SEQUENCE` so a `serial` default can see the sequence (`packages/pg-prime-kit/src/diff/ddl.ts:461-492`); alter rewrites all options (`packages/pg-prime-kit/src/diff/ddl.ts:1445-1451`).
- **Table.** Columns inline in ordinal order with defaults inline; `PARTITION BY` for a parent, a partition is created standalone then `ATTACH`ed with LK107 (`packages/pg-prime-kit/src/diff/ddl.ts:494-556`, `packages/pg-prime-kit/src/diff/ddl.ts:1337-1355`). Bound change = DETACH + ATTACH; key or `relkind` change = `unsupported_alter`; `SET [UN]LOGGED` → LK112 rewrite (`packages/pg-prime-kit/src/diff/ddl.ts:852-916`). Drop destroys all descendants, DS102 (`packages/pg-prime-kit/src/diff/ddl.ts:1035-1053`).
- **CLUSTER ON.** Consumes both the `index:` and the `constraint:` spelling of the index name, because a clustered index is usually a constraint's backing index (`packages/pg-prime-kit/src/diff/ddl.ts:1124-1136`).
- **Column add.** `ADD COLUMN IF NOT EXISTS` with the default inline (a separate `SET DEFAULT` would let NOT NULL fail on existing rows, `packages/pg-prime-kit/src/diff/ddl.ts:704-708`). MF103 for NOT NULL without default/identity/generated on a non-empty table (`packages/pg-prime-kit/src/diff/ddl.ts:611-613`); LK109 for a volatile default (`packages/pg-prime-kit/src/diff/ddl.ts:689`).
- **Volatile default split.** With `multiFile` and a nullable column: `ADD COLUMN` without default, then `SET DEFAULT`, plus a `volatile_default_split` info that `generate.ts` turns into a `-- pg-prime:data` stub (`packages/pg-prime-kit/src/diff/ddl.ts:634-688`). A NOT NULL volatile default instead warns `volatile_default_not_null` (`packages/pg-prime-kit/src/diff/ddl.ts:690-702`).
- **Column alter.** Type change → `TYPE … [COLLATE …] USING col::type`, rewrite, LK108/MF105/BC103; a collation-only change → `TYPE <same type> [COLLATE …]` with no `USING`, `rewrite: false`, LK113 (indexes rebuild, the table does not), plus MF107 when `namesColumn` finds the column in a unique index or a `p`/`u`/`x`/`c` constraint definition of the desired table and the table is not proven empty; removing a collation is `TYPE` with no `COLLATE` (`packages/pg-prime-kit/src/diff/ddl.ts:1861-1884`). Generated-ness changes and PG 18 `VIRTUAL` columns → `unsupported_alter` (`packages/pg-prime-kit/src/diff/ddl.ts:1890-1899`). Identity add → LK110 (`packages/pg-prime-kit/src/diff/ddl.ts:1900-1914`). Drop → `DROP COLUMN IF EXISTS`, DS103.
- **Collation limits.** A collation outside `pg_catalog` arrives already quoted and qualified and is emitted verbatim (`collationSql`). `namesColumn` is textual (string literals and `.`-qualified names are skipped), so it can over-report. An `ALTER … TYPE … COLLATE` on a column a view depends on fails in PostgreSQL like any type change, which is not detected at plan time.
- **SET NOT NULL.** Never a bare `SET NOT NULL` scan. When the desired side catalogues NOT NULL (PG ≥ 18) it is `ADD CONSTRAINT … NOT NULL … NOT VALID` + `VALIDATE` (`packages/pg-prime-kit/src/diff/ddl.ts:1964-1985`); otherwise a temporary `CHECK (col IS NOT NULL) NOT VALID`, `VALIDATE`, `SET NOT NULL`, `DROP CONSTRAINT`, with the temp name from `chooseConstraintName` (`packages/pg-prime-kit/src/diff/ddl.ts:1989-2017`). The choice is read from the catalog payload, not `server_version_num`. MF104 unless proven empty.
- **NOT NULL rename/validity.** PG 18 name change → `RENAME CONSTRAINT` (BC104); validation → `VALIDATE`; un-validation → DROP + `ADD … NOT VALID` (`packages/pg-prime-kit/src/diff/ddl.ts:2033-2067`).
- **Default.** Create/alter → `SET DEFAULT`, consuming `evaluates` edges so a new enum label commits first (`packages/pg-prime-kit/src/diff/ddl.ts:1373-1398`); skipped when the table or column is created by this plan (`packages/pg-prime-kit/src/diff/ddl.ts:560-562`). Drop skipped when the column is gone or dropped (`packages/pg-prime-kit/src/diff/ddl.ts:956-957`).
- **Constraint add.** Validated FK/CHECK → `ADD … NOT VALID` (MF106 unless empty/fresh) + `VALIDATE` under SHARE UPDATE EXCLUSIVE (`packages/pg-prime-kit/src/diff/ddl.ts:1531-1553`). PK/UNIQUE on an existing table with `concurrentOk` and a definition matching `PK_UNIQUE_DEF` → four `concurrent`-stage statements ending in `ADD CONSTRAINT … USING INDEX` (`packages/pg-prime-kit/src/diff/ddl.ts:1569-1629`). Otherwise literal `ADD CONSTRAINT` with LK104/MF101 or, under `noSafeRewrite`, LK105/LK106 (`packages/pg-prime-kit/src/diff/ddl.ts:1631-1656`).
- **FK ordering.** FKs consume, and their drops release, the referenced table's PK/UNIQUE constraints and unique indexes (`uniquenessProviders`, `packages/pg-prime-kit/src/diff/ddl.ts:1669-1680`).
- **Constraint alter.** Same definition, newly validated → `VALIDATE` only; anything else → drop + add (`packages/pg-prime-kit/src/diff/ddl.ts:783-800`). Dropping a PK/UNIQUE → DS106 (`packages/pg-prime-kit/src/diff/ddl.ts:1721`).
- **Index.** `%ID%` in the stored definition is replaced with a function so `$&`-style names are literal (`packages/pg-prime-kit/src/diff/ddl.ts:1760-1764`). Literal `CREATE INDEX` carries LK101 even on a table this plan creates; the concurrent form is `DROP INDEX CONCURRENTLY IF EXISTS` + `CREATE INDEX CONCURRENTLY`, both idempotent, ordered by phase (`packages/pg-prime-kit/src/diff/ddl.ts:1752-1816`). Alter = drop + create, MF102 when becoming unique (`packages/pg-prime-kit/src/diff/ddl.ts:764-781`). Drop → LK102.
- **Type.** Enum created with all labels; domain with named CHECKs spelled out; composite with ordinal-ordered attributes (`packages/pg-prime-kit/src/diff/ddl.ts:1198-1256`). Only domains alter in place (default, NOT NULL with MF104/LK107, CHECK add MF106/drop) (`packages/pg-prime-kit/src/diff/ddl.ts:1263-1327`). Composite attribute alters report `unsupported_alter` when any column uses the type (`packages/pg-prime-kit/src/diff/ddl.ts:1176-1196`). Drop → DS104.
- **Comment.** `COMMENT ON … IS text|NULL`, idempotent; skipped when the target is dropped by this plan or already gone (`packages/pg-prime-kit/src/diff/ddl.ts:974-987`). Targets without syntax throw (`packages/pg-prime-kit/src/diff/ddl.ts:1440-1441`).
