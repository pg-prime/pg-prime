# packages/pg-prime-context/src/index.ts

## Purpose
The `@pg-prime/context` entry: re-exports the host, its option and settings types, the structural
storage interface and the error class. `./testing` (`src/testing.ts`) is the second entry.

## Public API
- `TransactionHost` and the types `TransactionHostOptions`, `HostTxOptions`, `RequestScope`,
  `Propagation`, `Setting`, `Settings` (`packages/pg-prime-context/src/host.ts`).
- `AsyncStorage` (`packages/pg-prime-context/src/storage.ts:4`).
- `ContextError`, `ContextErrorCode` (`packages/pg-prime-context/src/errors.ts`).
- Not exported: `setPin`, `capture`, `restore`, `newStorage`.

## Flow
1. Importing the entry loads `host.js`, which imports `node:async_hooks` statically through
   `storage.js`; the only other import is `pg-prime`.

## Gotchas
- `src/unsupported-typescript.d.ts` is generated by `tools/api-snapshot.mjs`; never edit it by hand.
- The emitted `.d.ts` must not mention `node:*` (`tools/check-dts.mjs`), so `AsyncStorage` stays
  structural.

## Tests
- `packages/pg-prime-context/test/unit/host.test.ts` — "src imports only node:async_hooks and pg-prime".

- `fixtures/treeshake/context-basic/` — the module-set and size golden (`pnpm treeshake`).
